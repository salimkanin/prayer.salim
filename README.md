# 🕌 مواقيت الصلاة - تطبيق ويب إسلامي

تطبيق ويب لعرض مواقيت الصلاة بشكل جميل ومريح، مع مؤقتات للصلاة الحالية والقادمة.

## ✨ المميزات
- عرض مواقيت الصلاة لسنة كاملة
- مؤقت يظهر كم مضى على الصلاة الحالية
- مؤقت يظهر كم متبقي على الصلاة القادمة
- تنسيق الوقت بنظام 12 ساعة (AM/PM)
- تصميم إسلامي مع دعم الوضع المظلم
- متجاوب مع جميع أحجام الشاشات

## 🚀 كيفية الاستخدام
1. قم برفع الملفات على GitHub Pages
2. أو قم بتحميل الملفات محلياً وافتح index.html
